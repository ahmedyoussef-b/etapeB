## 2. Architecture

TERRAIN (rondier) -> BDD WEB (Neon/Postgres) -> BDD LOCALE (.data/ + Chroma)
                    tampon de transfert      source de vérité

La BDD Web est un tampon. Après transfert vers le local, elle peut être
purgée manuellement par un admin. Elle n'est pas la source de vérité.

## 4. Mécanismes de purge

### 4.1 purge-web (manuel, admin)

- Route : `POST /api/admin/purge-web`
- UI : `PurgeWebButton`
- Action : `DELETE FROM documents WHERE NOT path LIKE '%.placeholder'`
- Tables préservées : blocks, equipments, groups, group_equipments,
  procedures, human_resources, teams, mirror_repertoire, indexes,
  system_versions, users, sessions, _prisma_migrations

### 4.2 sync-purge (manuel, admin)

- Route : `POST /api/admin/sync-purge`
- UI : `SyncPurgeButton`
- Action : suppression ciblée de documents par path

### 4.3 reset (manuel, admin)

- Route : `POST /api/admin/reset`
- Action : truncate de 20 tables dans l'ordre FK-safe, puis re-seed
- Tables préservées : users, sessions, _prisma_migrations
- Tables truncées : execution_step_logs, procedure_media,
  procedure_executions, procedures, audit_logs, registration_requests,
  group_equipments, equipments, groups, blocks, mirror_repertoire,
  indexes, documents, human_resources, teams, publish_queue,
  user_sync_states, system_versions, reports, sync_logs

### 4.4 Purge automatique

Aucune. Confirmé par grep (`node-cron`, `setInterval.*purge`,
`schedule.*purge`) dans `src/` : résultat vide.

## 7. Points de vigilance

1. **Fichiers `.placeholder`** : jamais purgés par `purge-web` (2 lignes,
   négligeable).
2. **`SystemVersion`** : incohérence `purge-web` vs `reset`.
3. **`document_chunks`** : dans le schéma Prisma, absent de la base. Vit
   dans la BDD locale (Chroma).
4. **Modèles sans `@@map`** : `PublishQueue`, `UserSyncState`,
   `SystemVersion` en CamelCase SQL.

## 8. Règle de décision

- Table stable en volume -> on laisse.
- Table qui augmente en volume -> on purge ou on ajoute un mécanisme.
- Pour vérifier : comparer deux snapshots séparés de quelques jours.
